# Preparación de datos y análisis exploratorio: Wine Quality (UCI)

Flujo de *data wrangling* y EDA sobre el dataset **Wine Quality** del UCI Machine Learning Repository (vinos tintos y blancos, más de 15 variables fisicoquímicas).

## Qué incluye
- **Carga y perfilamiento**: estructura, tipos de variables y estadística descriptiva.
- **Calidad de datos**: detección y estrategia de tratamiento de valores nulos.
- **Selección de variables** relevantes para explicar la calidad del vino.
- **Visualización**: histogramas, scatterplots, boxplots, pairplot y heatmap de correlación con máscara (Seaborn).
- **Interpretación**: patrones de distribución, relaciones lineales y no lineales, y recomendaciones de análisis posteriores.
